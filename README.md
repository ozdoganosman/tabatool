# TabaTool - Sekme Yöneticisi 🚀

TabaTool, Chrome tarayıcınız için güçlü bir sekme ve yer işareti yönetim aracıdır. Favori sitelerinizi düzenli koleksiyonlar halinde organize edin, açık sekmelerinizi yönetin ve Chrome yer işaretlerinizi kolayca içe aktarın.

## ✨ Özellikler

### 📁 Koleksiyonlar
- Favori sitelerinizi kategorilere ayırın (İş, Haber, Sosyal Medya, vb.)
- Sürükle-bırak ile kolayca düzenleyin
- Tek tıkla kategorideki tüm siteleri yeni pencerede açın
- Her koleksiyonda istediğiniz kadar site saklayın

### 📑 Açık Sekmeler Paneli
- Tüm açık sekmelerinizi yan panelde görün
- Sekmeleri sürükleyip koleksiyonlara ekleyin
- Hızlıca sekme yönetimi yapın

### 📥 Yer İşareti İçe Aktarma
- Chrome yer işaretlerinizi kolayca içe aktarın
- Klasör klasör seçim yapın
- Yer işaretleriniz otomatik olarak koleksiyonlara dönüştürülür

## 🔧 Kurulum

1. Bu repoyu klonlayın veya ZIP olarak indirin
2. Chrome tarayıcınızda `chrome://extensions/` adresine gidin
3. Sağ üst köşedeki "Geliştirici modu"nu aktif edin
4. "Paketlenmemiş öğe yükle" butonuna tıklayın
5. Bu projenin bulunduğu klasörü seçin
6. TabaTool artık yeni sekme sayfanız olarak görünecektir!

## 📖 Kullanım

### Koleksiyon Oluşturma
1. "➕ Yeni Koleksiyon" butonuna tıklayın
2. Koleksiyonunuza bir isim verin
3. Site adı ve URL'leri ekleyin
4. "Kaydet" butonuna tıklayın

### Site Ekleme
- Koleksiyon modalında "➕ Site Ekle" butonuyla yeni siteler ekleyin
- Her site için bir isim ve URL girin

### Tüm Siteleri Açma
- Her koleksiyonun altındaki "🚀 Tümünü Aç" butonuna tıklayın
- Koleksiyondaki tüm siteler yeni bir pencerede açılır

### Açık Sekmeleri Yönetme
1. "📑 Açık Sekmeler" butonuna tıklayın
2. Yan panelde tüm açık sekmelerinizi görün
3. Bir sekmeyi sürükleyip bir koleksiyonun üzerine bırakın
4. Sekme otomatik olarak koleksiyona eklenir

### Yer İşaretlerini İçe Aktarma
1. "📥 Yer İşaretleri İçe Aktar" butonuna tıklayın
2. İçe aktarmak istediğiniz klasörleri seçin
3. "İçe Aktar" butonuna tıklayın
4. Yer işaretleriniz koleksiyon olarak eklenir

## 🎨 Özelleştirme

TabaTool şık ve modern bir tasarıma sahiptir:
- Gradient arka plan
- Yumuşak animasyonlar
- Responsive tasarım (mobil uyumlu)
- Koyu/açık tema desteği (tarayıcı ayarlarına göre)

## 🛠️ Teknolojiler

- Vanilla JavaScript (framework yok)
- Chrome Extension Manifest V3
- CSS3 ile modern tasarım
- Chrome Storage API
- Chrome Tabs API
- Chrome Bookmarks API
